# 认证数据模型

迁移：`apps/api/prisma/migrations/20261009023929_auth_foundation/migration.sql`。

| 表                 | 关键字段与约束                                                            | 用途                                               |
| ------------------ | ------------------------------------------------------------------------- | -------------------------------------------------- |
| `users`            | UUID 主键、状态、创建/更新时间                                            | 稳定内部用户身份，不以手机号作主键                 |
| `auth_credentials` | UUID 主键、`user_id` 外键、标识类型与登录标识联合唯一、密码哈希、验证状态 | 当前存手机号凭据；测试阶段保持 `UNVERIFIED`        |
| `auth_sessions`    | UUID 主键、`user_id` 外键、刷新令牌 SHA-256 哈希、版本、到期与撤销时间    | 轮换刷新令牌、立即退出、校验 Access Token 会话状态 |

注册使用数据库事务创建用户、凭据和首个会话，手机号唯一索引阻止重复账号；发生唯一冲突时整笔事务回滚。刷新使用旧令牌哈希作为条件执行 `updateMany` 原子更新，并递增版本，避免并发请求同时成功。退出按用户与会话 ID 撤销当前会话。

迁移仅新增三张表、三个枚举和相应索引/外键，不修改现有业务数据。该迁移已应用到开发库与独立的 `ridepilot_test` 测试库。回滚须先停用依赖这些表的 API，再按数据保留与账号迁移要求处理账户数据；不得在已有账户后直接删除表。
