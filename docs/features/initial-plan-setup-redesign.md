# 首次训练计划设置页优化

日期：2026-11-13

## 范围与交互

首次建计划的骑行基础、训练目标、时间安排、饮食与禁忌四页统一采用黑金暗色样式。前三页在固定标题右侧显示“下一步”，饮食页显示“生成”；标题左侧返回，移除四页底部重复的前进和返回按钮。页面滚动时标题及操作保持可见。

- 骑行基础：突出当前 FTP 和补录入口，按骑行经验、身体资料、训练状态与安全确认分组。
- 训练目标：使用带说明的方向选择行，FTP 功体比按需显示；训练周期作为滚动规划参考，不设目标达成日期，也不承诺在周期内达成目标。
- 时间安排：汇总每周可训练日和单次时长上限；星期可多选，时长单选，保留服务端已保存的非预设时长（例如 75 分钟）。实际课程按训练与恢复需要安排。
- 饮食与禁忌：分为饮食限制、补充说明、日常饮食习惯。选择“其他限制”时必须填写具体食物或成分；饮食字段仍仅存在本次引导状态中，暂不提交服务器或自动应用到饮食方案，页面明确说明这一边界。

顶部步骤轨道展示当前步骤。表单保存期间顶部操作显示加载状态，返回、表单和资料入口禁用。失败时保留输入，错误提示具有 alert 语义，并将表单滚回顶部方便查看。输入支持多行、滚动关闭键盘和 iOS 自动键盘内边距；内容在平板上限制最大阅读宽度。

## 实现边界

各步骤拆为独立组件，选择行和章节标题复用；引导类型移入 model，业务 hook 不依赖展示组件。赛事资料补录复用步骤组件，保留其独立导航方式。

未修改 API、共享契约、数据库或生成范围。首次建计划仍先创建近期训练草稿，经过预览、校验和用户确认后才应用；明显不适的生成阻断保持原有规则。
