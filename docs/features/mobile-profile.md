# 移动端 M01 我的与个人资料

## 1. 目的与范围

参考 `RidePilot_UI/design/screens/M01-profile.html` 实现移动端“我的”页面，并接入已有用户档案接口。页面只展示后端已支持的账户和基础运动档案字段，不使用设计稿中的目标、FTP、训练时间或饮食示例数据。

## 2. 当前实现

- 展示页面昵称、脱敏手机号、手机号验证状态、视图偏好和档案版本。
- 编辑并保存昵称、性别、年龄段、身高、体重、训练经验、训练意向、课程视图偏好和时区。
- 页面卡片、资料行分隔、间距和暗色信息区按 M01 设计稿对齐；未接入后端的设计稿示例模块不展示。
- 保存通过现有 `POST /api/v1/me/profile` 局部更新接口，提交 `expectedVersion`。
- 后端返回 409 时提示用户重新读取，避免静默覆盖其他设备更新。
- 退出登录沿用现有认证会话流程。

## 3. API 契约

| Method | Path                 | 权限         | 用途                       |
| ------ | -------------------- | ------------ | -------------------------- |
| GET    | `/api/v1/me/profile` | Access Token | 读取个人资料               |
| POST   | `/api/v1/me/profile` | Access Token | 局部保存个人资料和乐观版本 |

## 4. 未实现

目标与阶段、FTP/阈值历史、训练时间、饮食偏好、隐私导出/删除、设备同步和设置页没有对应后端 API，当前不展示为可用入口。
