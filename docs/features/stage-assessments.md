# 阶段测试与后续课程

## 目的与范围

将阶段的文字复评建议变成真实日程，支持手动录入 FTP、持续输出、固定路线结果，并将已保存证据传给后续课程草稿。关联 PRD M05、FR-401/404/406/407。当前不内置极限测试处方、设备导入、自动目标达成判定或自动阶段晋级；测试协议由用户选择并填写，设备适配推荐和具体安全阈值仍待产品确认。

## 使用流程

1. 训练 → 目标与阶段 →「阶段测试」标题右侧「+ 安排测试」，或阶段卡片测试建议旁的「安排测试」。自动关联目标、阶段，显示当前 FTP；没有 FTP 时引导设置，返回保留表单。
2. 选择类型、计划日期、方法。先预览同日课程/赛事/测试冲突，再确认；确认只添加日程，不删除原课程。存在冲突时可返回改日期，也可明确保留原安排。
3. 日历在有测试的日期显示标识，并列出所选日期的真实测试事件。目标页也展示测试列表，返回时刷新；整张测试卡片点击查看详情，分别展示类型、状态、日期和协议，右侧箭头提示导航。首次加载或读取失败时不显示“尚未安排阶段测试”，失败可重试，刷新失败保留可读数据。
4. 测试后打开「录入结果 / 调整状态」。完成需实际日期、方法、结果、来源、RPE；支持改期、跳过、未完成、无效及原因。已有完成结果可标记无效并保留历史证据。
5. 复评展示结果、同条件历史差值、阶段训练记录及证据限制。保存结果不更新 FTP；有效 FTP 测试可再单独确认更新。
6. 从复评选择后续阶段或日期范围，生成基于测试证据的课程草稿 → 差异预览 → 校验 → 确认应用。不会自动推进或改写阶段路线；FTP 改变后旧阶段失效，可重新生成阶段或选择日期课程。

## 字段与规则

- FTP：输入测试方案给出的最终 FTP，50–800 W；持续输出：实际秒数 + 平均 W；固定路线：路线名、秒数、距离 km。后两者不会换算成 FTP。
- 来源为骑行台/功率计/设备报告/手动记录，RPE 为 1–10；条件与备注选填。实际日期不晚于用户时区今天，计划/改期日期不早于今天。
- 比较必须同用户、目标、类型、协议、来源，双方明确确认可比且条件文本一致；持续输出还须相同时长，路线还须相同路线与距离。没有历史时作为基线，不制造进步或退步结论。当前保守地不比较同一实际日期的多次测试。
- 训练统计使用关联阶段开始日至实际测试日（不超过阶段结束日）的当前正式课程及稳定活动身份；未记录不是未完成，不能等同全阶段历史负荷。
- 改期事件同样作为课程生成和应用时的避让日期。用户明确确认同日保留课程时不会自动删除它；可另行生成课程调整草稿。
- 确认 FTP 检查测试版本、当前 FTP ID、测试类型/有效性、是否已应用及测量日期。旧测试不能覆盖日期更新的能力值；同日确认按顺序记录，保留原实际日期。能力更新不追溯修改历史课程功率。
- 已更新 FTP 后再标记测试无效不会删除能力测量历史，也不会自动回滚当前 FTP；复评明确引导去骑行功率设置单独更正。

## 实现边界

- 共享契约：`packages/contracts/src/assessments.ts`；范围请求增加可选测试 ID/版本。
- API：`coach/assessments.service.ts` 管理事务与状态写入，`assessment-schedule.service.ts` 管理冲突预览，`assessment-review.service.ts` 管理证据，mapper/validator 独立。原 CoachEvents 只保留活动与赛事。
- 移动端：`features/assessments` 按 screens/components/hooks/model/services 拆分。独立路由 `/assessments/new`、`/assessments/result`、`/assessments/[assessmentId]`；复用黑金组件与固定 `NavigationHeader` 短标题。
- AI：范围生成关联持久化的测试版本与复评证据，Skill adapter 1.3.0 解释保留/减少/延长/进阶的建议及差异。实际课程仍由既有服务校验和发布；应用前重查测试版本，变化则阻断。

## 一致性、错误与迁移

所有 API 需 Bearer 鉴权并验证归属。创建、状态修改、FTP 确认使用用户锁、事务、`Idempotency-Key`；修改还需 `expectedVersion`。独立幂等日志保存签名和原响应，响应丢失可安全重试。安排/改期在锁内重查预览指纹；赛事写入、手动 FTP 写入也共享该用户锁。

表单采用 React Hook Form + Zod，校验与失败不清空输入。不确定网络错误保留请求键，确定的业务错误可修正后重试。测试版本刷新保留录入值。提交中禁止返回/重复提交；未保存返回提示，转至设置再返回保留输入。日历两类数据独立处理错误，一类失败不隐藏另一类成功数据。

迁移 `20261030200000_stage_assessments` 为追加字段与新幂等表；已有测试标记 `LEGACY`，历史功率不视为已确认 FTP。旧版事件仍可读取、跳过、作废；需重新安排才能使用新类型录入。请求新增必填字段属于开发阶段契约升级，须前后端同时更新。详见 [API](../api/assessments.md) 与 [数据](../data/assessments.md)。
