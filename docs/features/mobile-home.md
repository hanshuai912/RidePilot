# 移动端首页 H01

## 1. 目的与范围

将 H01 首页设计稿落地为 React Native 页面，读取用户档案和正式计划状态。身体反馈、饮食、目标阶段和 AI 草稿不使用示例数据冒充真实结果。

## 2. 当前实现

- 首页保留五栏导航和 Premium Dark Performance 暗色视觉基线。
- 顶部根据本地时间显示问候语和日期，昵称通过 `GET /api/v1/me/profile` 读取，失败时回退为“骑行者”。
- `GET /plans/active/status` 返回无正式计划时展示安全空状态和 AI 建计划入口；已有正式计划时显示正式版本并跳转训练日历。状态读取失败时显示错误，不误报无计划。
- 身体状态显示“待评估”，不从缺失数据推断训练适宜性。
- 右上角头像进入现有“我的”页面。

## 3. API 契约

| Method | Path                          | 权限         | 用途                       |
| ------ | ----------------------------- | ------------ | -------------------------- |
| GET    | `/api/v1/me/profile`          | Access Token | 读取首页问候使用的页面昵称 |
| GET    | `/api/v1/plans/active/status` | Access Token | 判断正式计划是否存在及版本 |

## 4. 未接入内容

首页仍未展示今日训练详情、训练图表、训练反馈、饮食和补给、目标阶段、测试、赛事及 AI 建议草稿；不使用设计稿示例数据冒充正式业务数据。

## 6. 关联的 M01 个人页面

M01 的个人页面与资料编辑单独实现于 `apps/mobile/src/features/profile/`，使用现有 `GET/POST /api/v1/me/profile`。首页读取昵称和正式计划状态；个人页面负责编辑档案并提供 FTP 补录。饮食档案、隐私导出和设备同步仍未接入。
