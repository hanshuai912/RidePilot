# 移动端首页 H01

## 1. 目的与范围

将 H01 首页设计稿落地为 React Native 页面，同时只接入当前后端已经存在的用户档案接口。训练计划、身体反馈、饮食、目标阶段和 AI 草稿没有后端接口时不展示示例数据。

## 2. 当前实现

- 首页保留五栏导航和 Premium Dark Performance 暗色视觉基线。
- 顶部根据本地时间显示问候语和日期，昵称通过 `GET /api/v1/me/profile` 读取，失败时回退为“骑行者”。
- 无正式训练计划时展示安全空状态，不伪造课程时长、训练区段、餐食、测试日期或 AI 草稿。
- 身体状态显示“待评估”，不从缺失数据推断训练适宜性。
- 右上角头像进入现有“我的”页面。

## 3. API 契约

| Method | Path                 | 权限         | 用途                       |
| ------ | -------------------- | ------------ | -------------------------- |
| GET    | `/api/v1/me/profile` | Access Token | 读取首页问候使用的页面昵称 |

## 4. 未接入内容

今日训练、训练图表、训练反馈、饮食和补给、目标阶段、测试、赛事、AI 建议草稿均等待对应后端接口；首页不能使用设计稿示例数据冒充正式业务数据。

## 5. 验证

- 移动端 TypeScript 类型检查。
- 移动端首页和认证表单测试。
- 移动端 lint。

## 6. 关联的 M01 个人页面

M01 的个人页面与资料编辑单独实现于 `apps/mobile/src/features/profile/`，使用现有 `GET/POST /api/v1/me/profile`。首页只读取昵称；个人页面负责编辑和保存当前后端已支持的字段，并携带 `expectedVersion` 防止覆盖其他设备的更新。目标、FTP 历史、训练时段、饮食档案、隐私导出和设备同步仍等待后端接口。
