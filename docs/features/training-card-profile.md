# 训练卡片结构缩略图

2026-10-22：在移动端训练首页课程卡片中增加结构缩略图，参考 `RidePilot_UI/design/flows/training-flow-entry.html`。本次用户确认的范围是时间型动作绘图，不要求切换专业视图。

## 展示规则

- 在课程摘要与查看/编辑按钮之间展示阶梯色块、虚线参考线和阶段时长图例，沿用黑金暗色体系。热身、恢复、放松使用灰阶，训练使用低饱和绿色；颜色代表动作类型，不推断功率分区。
- 只绘制 `target.kind = duration` 的动作，按原始顺序排列。宽度为动作时长乘重复次数，占全部时间型动作总时长的比例；同一动作的重复次数合并为一块。
- 高度取强度范围平均值 `(min + max) / 2`，每条单位轴从零开始。上限为本轴最大平均值的 1.2 倍向上取整至 10，预留顶部空间。只用于课程内结构对比，不用于跨课程强度比较。
- 纯 W 或纯 %FTP 显示一行；混用时显示分别标注 W 和 %FTP 的两行，共用时间轴，另一单位的动作位置留空。当前训练接口仅有 `ftpAvailable`，没有可用于换算的 FTP 数值，因此不直接比较 W 和百分比，也不新增请求或伪造 FTP。
- 图例按动作类型汇总时间，包含重复次数。读屏描述依次提供各动作的类型、时长和平均强度。
- 距离型动作不绘图、不占宽度，也不影响高度或图例。课程卡片原有距离、动作数量和按钮保留。
- 无时间型动作、空动作列表或时间动作存在非法数值时隐藏整个缩略图，不补造训练数据。训练页加载、请求失败和重试继续沿用现有流程。

## 实现与数据边界

- `apps/mobile/src/features/training/model/workout-profile.ts`：筛选动作、时长/均值计算、分轴和图例数据。
- `apps/mobile/src/features/training/components/WorkoutProfileChart.tsx`：使用已安装的 `react-native-svg` 绘制自适应宽度图形，图例支持换行和字体缩放。
- `apps/mobile/src/features/training/components/Home.tsx`：在每张正式课程卡片中组合缩略图。

数据来自已鉴权的训练日历 API；不修改原始强度范围、详情/编辑数据或计划写入流程。无 API/共享契约变更、数据库迁移、新依赖或新的专业视图设置。
