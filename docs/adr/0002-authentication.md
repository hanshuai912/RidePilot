# ADR 0002：测试阶段认证与会话

状态：已采用（2026-10-09）

## 背景

PRD V1.3 要求手机号、测试验证码、密码与确认密码注册，手机号加密码登录，退出后当前会话结束。开发规范要求 JWT Access + Refresh、令牌安全存储/轮换和所有业务 API 默认鉴权。

## 决策

- 全局守卫默认拒绝未认证请求；公开接口须显式 `@Public()`。数据库会话检查使退出立即生效，未来业务服务仍须校验资源归属。
- Access JWT 有效期 15 分钟；Refresh JWT 有效期 30 天。数据库只存刷新令牌 SHA-256 哈希；每次刷新通过旧哈希条件更新来原子轮换，旧令牌不能再次使用。
- 密码使用 Node.js `scrypt`、随机盐及参数 `N=2^17, r=8, p=1`，哈希中记录版本和参数。未知手机号也执行同等强度的哈希验证，登录错误统一返回。
- Redis 为注册、登录、刷新提供按标识和 IP 的短期限流；键通过 HMAC 生成，避免直接保存手机号。
- 测试阶段任意 6 位数字验证码只检查格式，手机号验证状态固定为 `UNVERIFIED`。`AUTH_TEST_CODE_ENABLED` 在生产默认关闭，本地开发显式开启。
- 手机号暂按 PRD 建议的 11 位数字格式，特殊字符暂按可见 ASCII 标点符号范围执行。这两项是可调整的当前测试口径，尚非最终产品决策。

## 后果

每个受保护请求会查询数据库会话状态，以换取退出后的即时失效。未来若有高并发压力，可在不改变鉴权语义的前提下评估缓存。真实短信验证上线前需替换测试验证码逻辑并处理旧账号验证/迁移；不能把测试阶段的手机号视作已验证。新部署必须配置不同的 Access/Refresh 密钥并先应用认证迁移。

密码哈希参数参考 [OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。
