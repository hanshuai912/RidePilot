# 课程编辑统一专业模式

2026-11-09 用户确认：取消简洁和专业模式切换，全部采用专业模式。

此变更覆盖原产品 PRD FR-007、课程编辑双视图要求及 E2E-03 的切换验收。产品 PRD 位于独立的 `RidePilot_Product` 仓库，本开发仓库以本变更记录及[功能说明](../features/course-editing-preview.md)作为当前实现与验收依据。

- 人工新建、正式课程编辑、AI 候选局部编辑统一展示完整动作参数、结构图、动作顺序和合计。
- 移除模式切换、简洁模式整体比例调整、视图偏好 hook、客户端调用、专用 `GET/POST /me/profile/workout-view` API 与共享契约。
- 保留历史数据库偏好列，不迁移或改写课程数据；历史 SIMPLE 偏好不会降低编辑器信息密度。
- 动作增删改和排序、未保存提示、版本冲突、草稿校验及用户确认应用流程继续生效。

验收：直接进入任一编辑入口即可编辑完整参数；不显示模式切换，不发出偏好请求；排序后目标单位、强度和重复次数保持一致。定向测试位于 `workout-enhancements.test.tsx`，其他入口复用同一 `Editor` 并由 `training-routes.test.tsx` 覆盖。

后续交互变更：按用户要求将动作上下箭头替换为六点图标拖拽，保留统一专业编辑器。实现见 [课程编辑](../features/course-editing-preview.md)。
