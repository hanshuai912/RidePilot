# FTP-based cycling intensity reference

Adapted from `jelmervdm/skills` `coach/cycling/references/training-zones-and-metrics.md` at the commit recorded in `../UPSTREAM.md`. Percentages describe broad training zones; they are not a diagnosis or a guarantee of adaptation.

| Zone       | Approximate FTP range | Typical role                                                |
| ---------- | --------------------- | ----------------------------------------------------------- |
| Z1         | below 55%             | easy recovery                                               |
| Z2         | 55-75%                | aerobic endurance                                           |
| Z3         | 76-90%                | tempo and muscular endurance                                |
| Sweet spot | 88-93%                | controlled sustained work; overlaps Z3/Z4                   |
| Z4         | 91-105%               | threshold work                                              |
| Z5         | 106-120%              | short VO2-oriented intervals                                |
| Z6         | 121-150%              | brief anaerobic work requiring a supported training history |

Select a range for the actual workout purpose and athlete context. Do not turn these boundaries into a fixed weekly template. The API supplies FTP in watts and performs deterministic power and duration validation. Do not invent measured NP, TSS, IF, CTL, ATL or TSB from a planned interval list.
