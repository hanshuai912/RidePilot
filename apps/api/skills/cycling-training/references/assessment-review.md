# Cycling assessment review

Adapted from the pinned `mprecilio20` training-methods testing section and `jelmervdm` cycling power-zone reference. See `../UPSTREAM.md`.

- Review the supplied test protocol, result, date, status and conditions before interpreting it. Compare with a previous comparable test only when one is actually supplied. A single result does not establish a durable gain or loss.
- A postponed or skipped test is missing evidence, not a lower FTP. An invalid test must not be treated as a measured decline. If testing conditions differed, describe the comparison limit.
- Keep the recorded test and the current FTP measurement distinct. A test result does not automatically update FTP, change zone boundaries or alter historical workouts.
- Propose only future workouts within the editable scope. If evidence is weak or recovery is uncertain, prefer continuation or a lighter week with a later reassessment suggestion. Explain what future observation would support a stronger adjustment.
- The output's stage summary and assessment suggestion are explanatory text, not a guaranteed performance forecast or a scheduled medical test.
